# Локальная расшифровка речи из видео

Приложение расшифровывает речь из видеофайлов и сохраняет текст с таймкодами. Работает полностью локально — видео и аудио не покидают компьютер, данные не отправляются в интернет.

## Требования

- Python 3.10 или новее
- Пакеты: `faster-whisper`, `torch`, `imageio-ffmpeg`
- отдельный `ffmpeg` **не нужен** — бинарь поставляется вместе с `imageio-ffmpeg`

## Установка

```powershell
pip install faster-whisper torch imageio-ffmpeg
```

При первом запуске автоматически скачивается модель Whisper (это единственное обращение в интернет, и только за самой моделью). Далее всё работает офлайн.

## Использование

1. Положите видео в папку **`input`** рядом со скриптом (папка создастся автоматически при первом запуске).
2. Запустите скрипт:

```powershell
python transcribe.py
```

3. По завершении расшифровки появятся в папке **`output`** — по одному `.txt` файлу на видео.

### Поведение

- Обрабатываются **все** видео из папки `input` (`.mp4`, `.mkv`, `.avi`, `.mov` и другие).
- Видео, для которых в `output` уже есть `.txt` файл, **пропускаются** — при повторном запуске обрабатываются только новые.
- В консоль выводится отчёт: какие видео обработаны успешно, а при каких произошла ошибка. Ошибка одного файла не останавливает обработку остальных.
- В конце консоль ждёт нажатия клавиши, прежде чем закрыться.
- Поддерживаемые форматы: `.mp4`, `.mkv`, `.avi`, `.mov`, `.m4v`, `.webm`, `.mpg`, `.mpeg`, `.wmv`, `.flv`, `.ts`, `.m4a`.

## Формат расшифровки

Текст сохраняется в кодировке UTF-8, одна реплика на строку:

```
00:00:03: Привет, это моё видео.
00:00:07: Сегодня расскажу про локальную расшифровку.
```

## Настройка

Параметры задаются константами в начале файла `transcribe.py`:

| Константа | Описание | По умолчанию |
|---|---|---|
| `MODEL_SIZE` | Размер модели Whisper: `tiny`, `base`, `small`, `medium`, `large-v3` | `small` |
| `LANGUAGE` | Код языка (`"ru"`, `"en"` и т.д.); `None` — автоопределение | `None` |

Чем больше модель, тем выше точность, но медленнее работа и больше требования к памяти:

- `tiny` / `base` — быстрее всего, подходит для черновой расшифровки на слабых машинах;
- `small` — баланс скорости и качества (по умолчанию);
- `medium` / `large-v3` — максимальная точность, требуют мощный CPU или GPU.

## Устранение неполадок

- **Ошибка «Не установлен ни один из бэкендов»** — выполните установку из раздела выше.
- **Медленная обработка** — укажите меньшую модель (`MODEL_SIZE = "tiny"`) или используйте машину с GPU (поддерживается CUDA).
- **Ошибка при работе с видео** — убедитесь, что файл не повреждён и имеет поддерживаемый формат; остальные видео при этом продолжают обрабатываться.
