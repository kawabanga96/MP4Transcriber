Создал transcribe.py — полностью локальное приложение для расшифровки речи из mp4.

Как это работает:

Извлекает аудио из видео через ffmpeg (во временный WAV-файл).
Транскрибирует речь через Whisper (faster-whisper — приоритет, openai-whisper — резерв).
Сохраняет расшифровку в формат [ЧЧ:ММ:СС] Текст.
Конфиденциальность: все этапы выполняются локально — видео и аудио не покидают машину. Модель Whisper скачивается один раз при первом запуске, после чего инференс полностью офлайн.

Установка:

pip install faster-whisper torch
Запуск:

python transcribe.py video.mp4
# опции: -m small (модель), -l ru (язык), -o out.txt, --ffmpeg путь
Пример вывода в .txt:

[00:00:03] Привет, это моё видео.
[00:00:07] Сегодня расскажу про локальную расшифровку.
Примечание: на Windows без GPU первичный запуск модели и транскрибация займут время; для скорости/качества поставьте -m tiny (быстрее) или -m large-v3 (точнее).
